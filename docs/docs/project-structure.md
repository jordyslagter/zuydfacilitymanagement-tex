# Project structure

```
- main.tex <-- entry point of the document
- metadata.tex <-- metadata related to the document
- packages.tex <-- any packages you wish to add
- cover.tex <-- your own designed cover code (optional)
- bibliography.bib <-- bibliography entries
- frontmatter/ <-- frontmatter pages
    - [page].tex
- mainmatter/ <-- mainmatter pages
    - [page].tex
- appendix/ <-- appendix pages
    - [page].tex
```
