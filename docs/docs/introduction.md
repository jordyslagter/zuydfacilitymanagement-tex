# Introduction

This project aims to be a completely compliant
[Zuyd Facility Management Document Specification](https://zuydhogeschool.sharepoint.com/sites/GedeeldedocumentenFMletopbestandenenmappenzijngedeeldmetstud/Shared%20Documents/Forms/AllItems.aspx?viewid=2aba1969%2Df9d5%2D4efc%2Db9ce%2Ddf79c4eec57c&ga=1&id=%2Fsites%2FGedeeldedocumentenFMletopbestandenenmappenzijngedeeldmetstud%2FShared%20Documents%2FGeneral%2FHandleiding%20Verslaglegging%20FM%20%28let%20op%20map%20is%20gedeeld%20met%20studenten%21%29%2FHandleiding%20Verslaglegging%20FM%20versie%2030%20aug%2024%2Epdf&parent=%2Fsites%2FGedeeldedocumentenFMletopbestandenenmappenzijngedeeldmetstud%2FShared%20Documents%2FGeneral%2FHandleiding%20Verslaglegging%20FM%20%28let%20op%20map%20is%20gedeeld%20met%20studenten%21%29)
written in $ \LaTeX $.

It features a cover, title page, (optional) foreword, auto-generating
table-of-contents and a fully compliant APA7 bibliography.

If you have a suggestion or added feature, please open an issue or pull request
on the
[GitHub page](https://github.com/jordyslagter/zuydfacilitymanagement-tex)!
